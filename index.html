01 · Foundations

What is a Magnitude Comparator?

A combinational logic circuit that compares two binary numbers and reports their relative size — producing three mutually exclusive outputs: A>B, A=B, and A<B.

WHY IT'S NEEDED

Processors, memory controllers and embedded systems constantly have to decide "which value is bigger" — sorting, address decoding, range checks and loop conditions all reduce to this comparison.

REAL-WORLD USES

ALUs use comparators for branch conditions; routers use them for priority queues; industrial controllers use them for threshold checks.

  • Comparator vs. equality comparator — an equality comparator (built from XNOR gates) only answers "are they equal?", a single-bit output. A full magnitude comparator ranks the two numbers with three distinct outputs, so it needs extra logic to resolve inequality direction, not just mismatch.
02 · Building Blocks

Types of Comparators

From a single bit to n bits — the same priority principle scales through cascading.

1-bit Comparator

2 inputs3 outputsXNOR core

Compares single bits A and B. Since a bit can only be 0 or 1: A>B only when A=1,B=0; A<B only when A=0,B=1; and A=B when both bits match (an XNOR relation).

A>B = A·B′ A<B = A′·B A=B = A⊙B

2-bit Comparator

4 inputs16 rowsMSB priority

Compares A = A1A0 against B = B1B0. The MSB decides first — only if the MSBs are equal do the LSBs get a chance to break the tie. This "priority" idea is exactly what lets the design cascade to any bit width.

A>B = A1B1′ + (A1⊙B1)A0B0′ A<B = A1′B1 + (A1⊙B1)A0′B0 A=B = (A1⊙B1)(A0⊙B0)

4-bit Comparator

8 inputsIC 7485Cascadable

Extends the same MSB-priority rule across 4 bit pairs (A3A2A1A0 vs B3B2B1B0). This is the classic 74LS85 IC — it exposes cascading inputs so several 4-bit chips can be chained to compare 8, 12, or 16-bit numbers.

Comparison proceeds bit-by-bit from MSB (A3,B3) down to LSB (A0,B0). The first unequal pair, starting from the top, decides the result; if all four pairs match, A=B.

n-bit Comparator

GeneralizedRecursive logic

For n bits, examine bits from MSB (index n−1) to LSB (index 0). At each position, if the bits differ, that position alone determines A>B or A<B; if equal, move to the next lower bit. If every bit pair matches, A=B.

for i = n−1 downTo 0: if Ai ≠ Bi: result = (Ai > Bi) ? "A>B" : "A

04 · Derivation

Boolean Expressions

Step-by-step derivation of the 1-bit comparator equations from the truth table.

A>B

Only true for row A=1, B=0. Reading directly off the truth table:
A>B = A·B′

A<B

Only true for row A=0, B=1:
A<B = A′·B

A=B

True when A=0,B=0 or A=1,B=1 — the sum of both matching minterms:
A=B = A′B′ + AB = A⊙B

2-bit extension

MSB decides first; LSB only matters when MSBs tie:
A>B = A1B1′ + (A1⊙B1)A0B0′

08 · Where It's Used

Real-Life Applications

Comparators quietly run inside almost every digital system you touch.

01

ALUs & branching

CPUs use comparators to evaluate conditional branches (equal, greater-than, less-than checks).

02

Address decoding

Memory controllers compare address ranges to route reads and writes to the right chip.

03

Sorting networks

Hardware sorters chain comparators to reorder values without software loops.

04

Priority queues

Routers use magnitude comparison to decide which packet gets serviced first.

05

Threshold control

Industrial controllers trip alarms or relays once a sensor value crosses a set point.

06

Cascaded ICs

74LS85 chips chain to compare 8, 12 or 16-bit numbers for larger systems.
